# Проездной — Дневник поездок и расходов

## Описание
PWA-приложение для фиксации поездок на общественном транспорте и учёта расходов. Бухгалтерская модель: каждый расход записывается отдельно.

## Технологии
- Чистый HTML/CSS/JS (без фреймворков)
- PWA: Service Worker + manifest.json
- Хранилище: LocalStorage (нормализованная модель, совместимая с реляционной БД)
- Валюта: BYN (белорусский рубль)

## Модель данных (LocalStorage: `transit_diary`)

### passes — проездные
```json
{
  "id": 1,
  "type": "unlimited",
  "start_date": "2026-06-27",
  "duration": 30,
  "expires_at": "2026-07-27",
  "total_trips": null,
  "used_trips": 0,
  "price": 2500,
  "status": "active"
}
```
- `status`: "active" | "expired" | "lost"
- `type`: "unlimited" (по дням) | "fixed" (на N поездок)

### pass_transport — связь проездной ↔ транспорт (junction)
```json
{ "pass_id": 1, "transport": "ground" }
```

### trips — все поездки
```json
{
  "id": 1001,
  "ts": "2026-06-27T08:30:00",
  "transport": "ground",
  "pass_id": 1
}
```
- `pass_id`: FK → passes.id (null если разовая)

### expenses — все расходы
```json
{
  "id": 2001,
  "ts": "2026-06-27T10:00:00",
  "type": "pass",
  "price": 2500,
  "payment": null,
  "related_pass_id": 1,
  "related_trip_id": null
}
```
- `type`: "pass" (покупка проездного) | "trip" (разовая поездка)

### prices — цены за поездку
```json
{
  "ground": { "prepaid": 1.10, "cash": 1.15 },
  "metro": { "fixed": 1.15 }
}
```

## Экраны

### setup.html — Настройки
- Проездной: тип (нет / безлимитный / на N поездок), транспорт, срок, стоимость
- Цены за поездку: наземный (предоплата/наличные), метро

### index.html — Дневник поездок
- Карточка проездного с прогресс-баром
- Кнопки быстрого добавления: + 🚌 / + 🚇
- Журнал поездок за сегодня
- Статистика: всего поездок, расходов, по типам

## Логика
- Тап = быстрая запись (дефолтная цена, проездной если покрывает)
- Долгое нажатие = модал редактирования (время, цена, способ оплаты)
- Проездной потерян → поездки как разовые
- Отмена → удаление последней записи
