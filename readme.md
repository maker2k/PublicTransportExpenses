# Проездной — Дневник поездок

PWA-приложение для фиксации поездок на общественном транспорте и учёта расходов.

## Быстрое добавление

- **Тап** по кнопке транспорта — мгновенная запись поездки с дефолтной ценой
- Если есть проездной — поездка засчитывается через проездной (без расхода)

## Ручное добавление

- **Долгое нажатие** на кнопку транспорта — откроется форма добавления
- Можно выбрать: время, тип транспорта, цену, способ оплаты
- Доступны: 🚌 Наземный, 🚇 Метро, 🚗 Каршеринг, 🚕 Такси, 🛴 Самокат

## Журнал поездок

- На главном экране нажмите **«Сегодня: N поездок ›»**
- Откроется полный журнал с подробностями каждой поездки
- Кнопка **✖️** отменяет последнюю сегодняшнюю поездку

## Проездные

- Меню **«Проездной»** — создание и управление
- **Безлимитный** — 10, 15 или 30 суток
- **На N поездок** — 120 или 365 суток
- Может покрывать наземный, метро или самокат
- Поездка через проездной — без расхода
- Можно пометить как потерянный / восстановить / удалить

## Настройки

- **Цены за поездку** — наземный (предоплата/наличные), метро
- **Кнопки на главной** — какие виды транспорта показывать
- **Сброс** — удалить все поездки и проездные

## Расходы

- **Проездной** — разовый расход при покупке
- **Разовая поездка** — расход при оплате наличными/предоплатой
- Всего расходов — сумма на главном экране

## Технологии

- Чистый HTML/CSS/JS (без фреймворков)
- PWA: Service Worker + manifest.json
- Хранилище: LocalStorage (нормализованная модель, совместимая с реляционной БД)
- Валюта: BYN (белорусский рубль)

## Особенности

- Данные хранятся локально на устройстве
- Работает офлайн (установите как PWA)
- Тёмная и светлая темы
- Модель данных совместима с реляционной БД
